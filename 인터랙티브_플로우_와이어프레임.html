인터랙티브 뷰 클릭으로 탐색
📊 8단계 서비스 플로우
🎯 플로우 개요 사용자가 질문을 입력하면, AI가 실시간으로 CSV 데이터를 검색하고 자연어 응답을 생성한 후, 결과를 저장·공유할 수 있습니다.
1️⃣

사용자 입력

입력 사용자가 "마포 36㎡ 월세" 같은 자연어 질문을 입력하거나 FAQ 버튼을 선택합니다.

위치: 시작 화면 → 입력 화면

2️⃣

입력 검증

시스템 입력값이 3자 이상인지, PII(개인식별정보)를 포함하지 않는지 검사합니다.

처리: 길이 검증 → PII 감지 → 가드레일 확인

3️⃣

NLP 슬롯 추출

AI 입력 문장에서 자치구, 평형, 단지명, 의도를 추출합니다.

결과: {gu: "마포", size: "36", intent: "rent"}

4️⃣

CSV 검색 (RAG)

데이터 추출된 슬롯으로 임대료/공실률 CSV를 하이브리드 검색 (키워드 + 벡터)합니다.

결과: 1행 검색됨 (마포 36㎡ 월세 데이터)

5️⃣

신뢰도 계산

검증 검색된 데이터의 신뢰도를 계산합니다 (CSV 정확도 + 기준월 일치도).

점수: 95점 (신뢰도 높음) → 진행

6️⃣

LLM 응답 생성

AI CSV 데이터와 사용자 질문을 토대로 자연어 응답을 생성합니다.

생성 항목: 한 줄 결론 + 짧은 설명 + 후속 질문 제안

7️⃣

응답 포장 & 피드백

UI CSV 데이터를 숫자 카드로 표현하고, 출처를 명시합니다.

표시: 월세 카드 + 보증금 + 기준월 + 후속 버튼

8️⃣

결과 저장 & 공유

완료 사용자가 결과를 저장하거나 카톡으로 공유할 수 있습니다.

동작: 3줄 요약 → 복사/공유 → 데이터 저장
